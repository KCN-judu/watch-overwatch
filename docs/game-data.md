# 游戏数据

来源：本机安装的国服守望先锋（`D:\Overwatch`，版本 2.25.0.0.154461，简体中文文本）。用 OWLib 的 DataTool v2.25.0.0+1151 解包（GitHub `overtools/OWLib` 发布页，75 MB，与游戏版本同一天发布），只读游戏目录，不改游戏文件。

整理出来的可用资源在 `resources/game/`，说明见 `resources/game/README.md`。

## 一、官方怎么组织信息

游戏本体里的数据结构，比官网页面和大神目录更接近“官方的信息模型”。

| 实体 | 官方的组织方式 | 对我们界面的启发 |
|---|---|---|
| **英雄** | 一个英雄 = 职责（重装/输出/支援）+ 描述 + **载具列表（Loadouts）** + **威能（Perks）** + 图片。共 54 个英雄，每个都有子职责 | 英雄页的信息单位应当是“职责 → 子职责 → 英雄”三级，而不是平铺一列 |
| **载具列表** | 每一项都有固定类别：武器、技能、终极技能、被动技能、**子职责**、英雄属性。类别决定图标的外框和位置 | 技能图标要按类别分组显示，终极技能单独标出 |
| **子职责** | 官方把它放在英雄的“被动”一栏里，名称形如“副职责：奇袭”，附一句被动效果。10 种，全部英雄都有 | 它是玩法定位，不是装饰；悬停显示被动说明是对的 |
| **威能** | 每个英雄固定 4 个：两个一级（小）、两个二级（大），都有名称、说明、图标 | 对局详情里一级二级各显示 2 个图标是对的；还可以显示说明 |
| **地图** | 每张地图有官方类型：攻防两队互换（OffenseDefenseMap）、镜像（MirroredMap）、剧情（PVE），再加进攻/防守两个状态名；有变体（圣诞节国王大道、万圣节好莱坞）、缩略图、旗帜图 | 地图的“玩法类型”不在地图表里，而是由模式决定；变体地图要归到同一张基础地图下 |
| **模式** | 267 张模式图片，名称很细：竞技、快速、决斗先锋 3V3/5V5、街机活动、故事模式四档难度（普通/困难/专家/传奇）等 | 我们现在只有三种队列，官方还有更多街机模式；难度四档有 60×60 的官方小图标 |
| **图标** | 1521 个界面矢量图（SVG）和两万多张界面纹理。矢量图大多是通用界面零件（箭头、边框、勾叉），也有官方的职责三件套、段位、各英雄剪影 | 通用零件不值得收；值得收的是职责、英雄剪影、技能和威能 |

## 二、已经用上的

- **职责图标**：三个官方矢量图（盾牌、子弹、十字，对应游戏内编号 0x20、0x21、0x22），替换了原来 128px 的位图，缩放不再发糊。
- **子职责**：用游戏里的名称和被动说明，54 个英雄全部对上。核对结果：和之前的表只差一处，黑影在游戏里是先锋（OverFast 数据是战术，已过时）。

## 四、没有找到的

- **玩法类型图标（占领要点、运载目标这些）**：游戏里的模式图片是带背景的大卡片（700×500），不是干净图标；矢量图我只浏览了前 500 个左右，没有认出来（没有看完）。应用现在用的是 OverFast 的玩法图标，继续用。

## 五、怎么重新解包

游戏更新后数据会变。重新解包的步骤：

1. 从 `https://github.com/overtools/OWLib/releases` 下载与游戏版本对应的 `toolchain-release.zip`，解压到一个空目录。
2. 在该目录里运行（国服加 `--rcn`，语言用 `--language=zhCN`）：

```
DataTool.exe "D:/Overwatch" list-heroes --language=zhCN --rcn
DataTool.exe "D:/Overwatch" list-maps --language=zhCN --rcn --json
DataTool.exe "D:/Overwatch" extract-hero-icons <输出目录> --language=zhCN --rcn
DataTool.exe "D:/Overwatch" extract-vector-images <输出目录> --language=zhCN --rcn
DataTool.exe "D:/Overwatch" extract-gamemode-images <输出目录> --language=zhCN --rcn
```

3. `--json` 的结果输出在标准错误流（`2> 文件`），不是标准输出。
4. 参数要写成 `--language=zhCN` 这种带等号的形式，空格分隔会报错。
5. 游戏版本太新、工具还没更新时会失败；这次版本（2.25）是同一周发布的，成功。
