# 按问题找答案

常见的几个问题，各自去哪里看、怎么读。每个数字的定义见 [指标口径](metrics.md)。

## 为什么掉分了？

1. **赛季走势 → 段位轨迹**：看是哪个职责在掉，从什么时候开始。虚线是赛季分界。
2. **掉分时对面强不强**（同一页下方）：每段掉分写明几胜几负、对面平均比我方高多少。对面高 100 分以上（一个小段）且多数场次如此，多半是匹配到了更强的对手，而不是打得更差了。这一项要那几场有对局强度：打开它们的详情或在对局强度页分析过。
3. **概览 → 值得注意**：“近期胜率明显更低”时，下一条会写“主要来自”哪张地图或哪个英雄，点一下直接看那些对局。“一次连着打时后面几场明显变差”说明该休息了。
4. **对局强度**页：选职责和场数做一次完整分析，看最近这些对局里双方的平均段位分。

## 该练哪个英雄？

1. **英雄**页按胜率排序时用的是区间下限：排在前面的是“至少有这么高”的，不是碰巧赢了几场的。
2. 点开英雄看 **同侪对比**：这个英雄的每项数据在差不多段位的同英雄玩家里排第几。后 10% 的那一项就是最该补的。
3. **对比** 两个英雄（英雄详情右上角）：同职责的两个英雄并排看胜率区间和每 10 分钟数据。样本不到 5 场时会提示数字不稳定。
4. **地图**页点一张图，看“在这张图上玩什么”：同一张图上哪个英雄赢得多。

## 进步了吗？

1. **成长**页每个指标一张卡片：存活时长、Fleta、KDA、治疗、阻挡，写“上升 / 下降 / 看不出变化”和可信度。按职责看，不要看“全部”。
2. 点 **对比前一段**：最近一段和之前同样多的一段逐场对齐，写明两段平均和差值。
3. 图上的灰色底带是该玩家之前 20 场的通常范围，跳出底带的才是真变化。
4. **概览 → 回顾**的“进步最大的一项”取的就是成长页里上升幅度最大的指标。

## 这局输在哪？

1. **对局**页点开这场：双方 10 人的数据条按全场最大值缩放，▲ 是队内最高。
2. 看双方的段位列：对面整体高很多，输得不冤。
3. 点该玩家进入个人页：本场数据占本队的比例、Fleta、威能；和同队同职责的人比一比。
4. 想看同一张图上是不是一直输：**地图**页点这张图，“查看这张图的对局”。

## 怎么看对局强度？

1. 一场的强度 = 一队已定级玩家的平均段位分；差 = 己方 − 对方，正数表示己方更强。
2. 段位依次取本场段位、本赛季同职责段位、本赛季其他职责里最高的；都没有的玩家不计入，不当 0。
3. 走势图上每场一个点，竖条是这一队最低到最高的段位分；中间缺数据的对局画成阴影带。
4. 结论要看场数：5 场的平均很不稳定，20 场才比较可靠。
