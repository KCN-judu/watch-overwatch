# 按问题找答案

几个常见问题各去哪里看、怎么读。每个数字的定义见 [指标口径](metrics.md)。

## 为什么掉分了？

1. **赛季走势 → 段位轨迹**：哪个职责在掉，从哪一场开始。虚线是赛季分界。
2. **掉分时对面强不强**（同一页下方）：每段连续掉分写明几胜几负，以及对面平均比己方高多少分。只统计算过对局强度的场次（打开过详情或在对局强度页分析过）。
3. **概览 → 近期动态**：“状态下滑”下面的“下滑来源”列出主要是哪张图或哪个英雄，点一下看那些对局；“连续第 4 场起胜率 …”是一次连着打时后几场和前 3 场的对比。
4. **对局强度**：选职责和场数分析一次，看这些对局里双方的平均段位。

## 该练哪个英雄？

1. **英雄**页按胜率排序用的是置信区间下限：排在前面的胜率“至少这么高”，不是碰巧赢了几场。
2. 英雄详情的 **同分段对比**：这个英雄每项数据在段位相近的同英雄玩家里排第几百分位。
3. 英雄详情的 **对比**：两个英雄并排看胜率区间和每 10 分钟数据；不足 5 场会注明。
4. **地图**页点一张图，看“本图英雄”：这张图上各英雄的胜率。

## 进步了吗？

1. **成长**页每个指标一张卡片：存活时长、Fleta 指数、KDA、治疗量、阻挡量，写上升 / 下降 / 无明显趋势，以及 显著 / 弱趋势 / 无变化。按职责看，“全部”混了不同职责的数值。
2. **对比前一段**：最近一段和之前等长的一段逐场对齐，写明两段平均和差值。
3. 折线图的灰色底带是前 20 场的四分位区间（P25–P75），带外的是异常局。
4. **概览 → 回顾**的“提升最大”取的是成长页里上升幅度最大的指标。

## 这局输在哪？

1. **对局**页点开这场：双方 10 人的数据条按全场最大值缩放，▲ 是队内最高。
2. 段位一列：双方这一场的段位快照，对局强度用的是同一份。
3. 点一名玩家进入卡片：本场数据占本队的比例、Fleta 指数、威能。
4. 同一张图上的其他对局：**地图**页点这张图 →“查看本图对局”。

## 怎么看对局强度？

1. 一场的强度 = 一队已定级玩家的平均段位分；差 = 己方 − 对方，正数是己方高。
2. 每名玩家的段位依次取：这一场自带的段位、本赛季所打职责的段位、本赛季其他职责里最高的。都没有的不计入，不当 0。
3. 走势图上每场一个点，竖条是这一队最低到最高的段位分；中间缺数据的场次画成斜线阴影带。
4. 场数少时平均值波动大：5 场的结果很不稳定，20 场稳定得多。
