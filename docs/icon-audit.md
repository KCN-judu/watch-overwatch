# 守望先锋固定语义图标盘点

目的：找出游戏里有固定图标的概念，对照我们界面现在是怎么表示的，列出还没有替换的，并核实每一项的数据来源。

数据来源：大神目录 `query_tool.json`（两份，用较新的一份）、Overstats 的资源与代码、真实采集样本、暴雪官网（国际站 `overwatch.blizzard.com`、国服站 `ow.blizzard.cn`）、公开的 OverFast API（`overfast-api.tekrop.fr`）。

排序原则来自 skill 的图标规范（`ui/iconography.md`）：预算花在“在密集重复场合反复出现”的概念上；领域自己的标准图标原样复用；一次性出现的概念用文字更好。

## 三、游戏里有固定图标，数据里没有，但找到了公开来源

OverFast 是公开的第三方接口，数据源自暴雪官网。它不是大神的数据，名称是英文，需要自己对应到中文。素材都下载进应用，运行时不依赖它。

| 概念 | OverFast 提供什么 | 对应关系 | 核实结果 | 建议 |
|---|---|---|---|---|
| **地图玩法类型** | `/gamemodes` 14 个 SVG 图标，40×40，白色填充，每个 1–4 KB；也可按需下载后放进应用 | 目录里的中文玩法能对上：占领要点 = control、运载目标 = escort、攻击/护送 = hybrid、机动推进 = push、闪点作战 = flashpoint、攻防阵线（花冈、阿努比斯王座）= clash | 下载了 control、escort、hybrid、push、flashpoint、clash、assault 七个，都能取到。真实数据验证：一名玩家的 25 场快速比赛里，玩法是运载目标 10、攻击/护送 7、占领要点 5、机动推进 3，全部在这六种之内，且每张地图都能在目录里查到玩法 | **高**。出现在每一行，现在只有一行小字，换成图标最划算 |
| **职责（矢量版）** | `/roles` 官方 SVG，来自暴雪内容库 | 与现有位图一一对应 | 能取到；比现在的 128px 位图清晰，也不依赖 Overstats 的资源 | 中。矢量版可以替换位图 |
| **英雄技能** | `/heroes/{key}` 每个英雄 4–6 个技能，含图标（和大神同一个图片域名） | 需要把英雄 GUID 对应到英文 key；目录里有官方 ID，可以通过 OverFast 的英雄名单（54 个，含 portrait）对上 | 取到安娜的 4 个技能，有图 | 低到中。可以放在英雄页的立绘面板里 |
| **子职责**（共 10 种） | **官方有**，见下一节：每种一个官方 SVG | 英雄页能取到 | 已下载 | 见下一节 |


### 官方站点实际查到的结果

逐页查了暴雪官网。结论：官方站点只在英雄详情页放了一批固定语义图标，其余都没有。

| 官方页面 | 能拿到什么 | 结果 |
|---|---|---|
| 国际站英雄详情页 `/en-us/heroes/<英雄>/` | **子职责图标**（40×40 白色 SVG，每个 1.3–2.1 KB）、英雄技能图标、威能图标（一二级各 2 个，和大神同一个图片域名）、体育场图标 `ph_stadiumicon.svg` | **子职责 10 种全部取到**，已放进 `app/assets/subroles/`，并附英雄到子职责的对照表 `hero_subrole.json`（官网抽样 42 个；另 12 个新英雄按 OverFast 英雄清单补进了界面代码）。中文名（国服第 1 赛季职责改版，据游民星空新闻核对）：重装 = 斗士 Bruiser、先锋 Initiator、铁壁 Stalwart；输出 = 神准 Sharpshooter、奇袭 Flanker、专业 Specialist、侦察 Recon；支援 = 战术 Tactician、医疗 Medic、生存 Survivor |
| 国际站英雄总览页 | 职责图标 `dark_circle_*.svg`（圆底）和 `Tank/Damage/Support.svg` | 官方矢量职责图标，可替换现在的位图 |
| 国际站 `/rates`（英雄胜率页） | 页内嵌入每个英雄的胜率、选取率、禁用率、头像、子职责、职责图标的 JSON | 没有新图标；但英雄到子职责的对照可以从这里一次取全 |
| 国际站 `/maps` | 营销页，没有地图列表和玩法图标 | 没有 |
| 国际站 `/gamemodes`、`/competitive` | 404 | 没有 |
| 国际站 `/career` | 需要登录 | 无法取 |
| 国服官网 `ow.blizzard.cn` 及 `/heroes/` | 页面几乎只有社交图标和二维码，内容靠脚本加载 | 没有 |
| 官网脚本包 | 只有商店徽标 | 没有 |

所以：
- **玩法类型图标官方站点没有**。OverFast 的 14 个玩法图标是它自己托管的（域名是 `overfast-api.tekrop.fr/static/gamemodes/`），不在暴雪的内容库里。这一项仍然用 OverFast 的文件。
- **职责矢量图标官方有**，可以直接替换。
- **子职责图标官方有**，之前写“拿不到”是没查到官方英雄页，现在补上。
- 计分板数据项、奖牌、荣誉类别、队列类型、赛季图标、终极技能：官方公开页面里都没有，和第四节一致。

## 四、游戏里有，我们的所有来源里都没有

| 概念 | 游戏里的样子 | 我们现在 | 说明 |
|---|---|---|---|
| **计分板数据项**（消灭、助攻、阵亡、伤害、治疗、阻挡） | 计分板列头是固定图标 | 文字列头 K/A/D、伤害、治疗、阻挡 | 目录里的 `behaviorIcon` 5 张实际是“伤、疗、挡”之类的汉字徽标，深色主题下几乎看不见，不算语义图标，所以没用 |
| **游戏模式**（竞技、快速、角斗领域） | 游戏有各自的模式图标 | 通用的奖杯、闪电、体育场图标 | Overstats 用 `comp.png`（粉色翅膀徽章）当竞技模式标志，快速比赛是它自己画的闪电，所以它也没有官方快速图标；这和我们的做法一致。`fight.png`（橙色奖杯）在 Overstats 代码里没有被引用，用途未确认 |
| **奖牌**（金银铜） | 每项数据的最高标记 | 用“▲”表示大神标记的最高值 | 没有素材；“大神标记的最高值”和游戏奖牌语义是否一致我没有验证 |
| **荣誉类别**（指挥、队友、体育精神） | 三个固定图标 | 只显示总等级 | 没找到来源 |
| **队列类型**（职责队列、开放队列、6v6） | 固定图标 | 文字 | 没找到来源 |
| **赛季图标** | 每个赛季有徽标 | 文字“S25” | 目录 `seasonList` 只有文字；Overstats 的 `season_logo/` 里只有一张背景图 |
| **终极技能** | 固定图标 | 没有 | 目录 `heroConfig` 只有纹理 GUID，没有图片地址；OverFast 的技能列表里没有单独标注终极技能 |

## 五、不建议加图标的

- 胜、负、平：游戏里是文字横幅，不是图标；我们用对勾、叉、横线加文字，已经满足“形状加文字”。
- 账号暂停、数据缺失、覆盖率：没有对应的游戏图标，保留文字和通用警告图标。
- 只出现几次的概念（设置页里的各项）：文字比图标好。

## 六、按价值排序的建议

1. **玩法类型图标**（出现在每一行；官方没有，用 OverFast 的文件）。
2. **威能图标**（每名参与者都有，数据已确认）。
3. **英雄熟练度徽章**（英雄页每一行，对应关系已核实）。
4. **异能与装备图标**（角斗领域，数据已有，但没拿真实对局验证）。
5. **子职责图标**（官方 SVG 已下载；英雄页和英雄行可以显示，比如“医师”“神射”）。
6. 职责图标换成官方矢量版、英雄横幅作行背景。
7. 英雄段位：先验证有没有数据。

## 七、实现时要注意

1. 白色剪影图（职责、威能、玩法）必须按主题着色，深色浅色都要看得见；彩色图（异能、装备、徽章）不着色。SVG 要用 `flutter_svg`（纯 Dart，不需要原生插件）。
2. 每个图标都要有无障碍名称和提示，像职责那样在列头放图例。玩法图标没有图例的话，用户得记 6 个新图形，所以第一次出现时要带文字名。
3. 异能、装备有上千个，不要预先下载；按需从地址加载，加载失败退回文字名。玩法、职责只有十几个小文件，可以直接放进应用。
4. OverFast 是第三方接口，可用性没有保证，所以图标要放进应用里，不要在运行时依赖它。

## 八、没有核实的地方

- 英雄段位在竞技玩家身上是否有数据。
- 威能 66/67 的命中率只在一名玩家的 5 场数据上验证。
- 异能、装备在真实角斗领域对局里的命中率。
- 只验证了一名玩家的快速比赛，没有验证排位和角斗领域里会出现哪些玩法。
- 攻防阵线对应 clash 是按地图（花冈、阿努比斯王座）推断的；攻防作战、死斗、决斗先锋、勇夺锦旗的对应也只是按名称推断。行动任务、动感斗球、英雄精通、教学和合作模式不在 OverFast 的 14 种里。
- `fight.png` 的用途。
- 12 个新英雄的子职责来自 OverFast，没有逐个对官网页；其中同一子职责内的中文名（如 斩仇/死怨/安燃 都是奇袭）是按职责和数量对的，不影响图标。灰机 wiki 的“副职责”页被安全验证拦住，没读到。
- 国服官网内容靠脚本加载，静态页取不到；如果国服站有独立的图标，需要用浏览器渲染后才能查。
- “大神标记的最高值”和游戏奖牌的关系。
