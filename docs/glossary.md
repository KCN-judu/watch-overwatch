# 术语表

界面和文档共用一套词。

| 用词 | 意思 | 不用 |
|---|---|---|
| 本人 | 正在查看的玩家，需要和其他玩家区分时用；多数句子不写主语 | 你、该玩家、查询对象 |
| 大神 | 网易大神，对局和段位数据的唯一来源 | 上游 |
| 对局 | 一场比赛 | 比赛记录、战绩、游戏 |
| 对局列表 | 大神给的对局摘要（时间、地图、英雄、比分、本人数据），从新到旧 | 战绩列表 |
| 对局详情 | 一场的完整数据：双方 10 人的数据、段位、组队、威能 | 比赛详情 |
| 已读取 / 已存 | 已读到本机并保存的对局列表或详情；大部分分析只用它们，不请求大神 | 缓存（只用于设置页“本地缓存”和“走缓存”这类请求说明） |
| 模式 | 竞技比赛、快速比赛、角斗领域，数据互不混算 | 排位、匹配、队列、玩法 |
| 职责 | 重装、输出、支援 | 位置、定位 |
| 己方 / 对方 | 本人所在的队 / 另一队 | 我方、敌方 |
| 段位 / 小段 | 青铜 … 英杰，每个段位 5 个小段（5 最低，1 最高） | 段、星、等级 |
| 段位分 | 段位换成的连续分数（500–5000），见 [指标口径](metrics.md#rating) | 分数、SR、MMR |
| 段位快照 | 读入一场对局时查到的参与者本赛季三个职责的竞技段位，和对局一起存，查到后不再改 | 生涯段位、段位缓存 |
| 段位同步 | 后台给最新 300 场对局补段位快照 | 段位查询任务 |
| 已定级 / 未定级 | 本场有段位，或段位快照里有段位 / 都没有 | 已评定 |
| 胜率 | 胜 ÷（胜 + 负），平局和结果未知不计 | |
| 置信区间 | 胜率的 95% Wilson 区间，见 [指标口径](metrics.md#win-rate-range) | 可能的范围、误差 |
| 样本不足 | 分出胜负不到 5 场（走势不到 8 场），只列出不比较 | 数据太少 |
| 显著 / 弱趋势 / 无变化 | 走势检验 p < 0.05 / p < 0.1 / 其余，见 [指标口径](metrics.md#confidence) | 较可信、有迹象、看不出变化 |
| 对局强度 | 一场里双方已定级玩家的平均段位分，见 [指标口径](metrics.md#strength) | 对手强度、实力、匹配强度 |
| 同分段 | 本机已存对局里段位相近、用同一英雄的其他玩家，见 [指标口径](metrics.md#percentile) | 同侪、同水平玩家 |
| 近期动态 | 概览页里证据够的几条结论，见 [指标口径](metrics.md#threshold) | 值得注意、洞察 |
| 强势图 / 苦手图 | 胜率置信区间整体高于 / 低于总胜率的地图 | |
| 绝活 / 短板英雄 | 胜率置信区间整体高于 / 低于总胜率的英雄 | |
| 一段 | 相邻两场间隔不超过 5 小时的一串对局（每日总结的“分 N 段”） | session、一次连着打 |
| 组排 / 单排 | 同队至少一人与本人组队 / 同队全是路人 | 开黑、车队 |
| 常遇玩家 | 在本人已存详情里同场至少 2 场的玩家 | 好友、队友（不一定是好友） |
| 每 10 分钟 | 折算成每 10 分钟的量，见 [指标口径](metrics.md#per-10) | /10min |
| 更新于 | 数据最后一次读取的时间 | 采集于 |
| 搜索 / 筛选 | 文本框里的过滤 / 筛选标签 | |
| 查找玩家 | 按战网昵称找到一名玩家 | 搜索玩家 |
| 示例玩家 | `示例玩家#0000`，生成的数据，不需要账号、不请求大神；只在开发构建里有 | 演示账号 |
