# 术语表

界面和文档用同一套词。左列是用的词，右列是它的意思和不用的说法。

| 用词 | 意思 | 不用 |
|---|---|---|
| 该玩家 | 正在查看的那名玩家（被查询的对象） | 你、查询对象（只在开发文档里用） |
| 对局 | 一场比赛 | 比赛记录、游戏 |
| 对局列表 | 上游给的对局摘要（时间、地图、英雄、比分、本人数据），按时间从新到旧 | 战绩列表 |
| 对局详情 | 一场的完整数据：双方 10 人、每人的数据和段位、组队、威能 | 比赛详情 |
| 本机已读取 / 已存 | 已经读到本机并保存的对局列表或详情。大部分分析只用它们，不向上游请求 | 缓存（只在设置页的“缓存”里用） |
| 竞技比赛 / 快速比赛 / 角斗领域 | 三种模式，数据互不混算 | 排位、匹配 |
| 职责 | 重装、输出、支援 | 位置、定位 |
| 段位 / 小段 | 青铜 … 英杰，每个段位 5 个小段（5 最低，1 最高） | 段、星 |
| 段位分 | 段位换成的连续分数，见 [指标口径](metrics.md#rating) | 分数、SR（界面不用） |
| 已定级 | 有段位（本场或生涯）的玩家 | 已评定 |
| 胜率 | 胜 ÷（胜 + 负），不计平局 | |
| 可能的范围 / 区间 | 胜率的 Wilson 区间，见 [指标口径](metrics.md#win-rate-range) | 误差、置信区间（界面不用） |
| 样本不足 | 分出胜负不到 5 场，只列出不比较 | 数据太少 |
| 对局强度 | 一场里双方已定级玩家的平均段位分，见 [指标口径](metrics.md#strength) | 对手强度、MMR |
| 同侪 | 本机对局里差不多段位、用同一英雄的其他玩家 | 同水平玩家 |
| 一次连着打 | 相邻两场间隔不超过 5 小时的一串对局 | session、一个时段 |
| 组排 | 同队里有人和该玩家组队 | 开黑、车队 |
| 常遇玩家 | 在该玩家已存对局里出现 2 次以上的玩家 | 好友、队友（不一定是好友） |
| 每 10 分钟 | 折算成每 10 分钟的量，见 [指标口径](metrics.md#per-10) | /10min |
| 更新于 | 数据最后一次读取的时间 | 采集于 |
| 搜索 | 文本框里的过滤 | 筛选（只指筛选标签） |
| 查找玩家 | 按战网昵称找到一名玩家 | 搜索玩家 |
| 示例玩家 | 不需要账号就能浏览的生成数据，玩家名带“示例” | 演示账号 |
