# Watch Overwatch

国服守望先锋的对局与数据分析桌面应用（Windows 10/11，64 位）。从网易大神读取玩家的对局、英雄和段位数据，整理成统一的数据结构，再做对局强度、成长走势等分析。界面是 Flutter 原生程序，数据由同目录的本机服务 `watchd`（Rust）读取，两者都只在本机运行。

![对局列表](images/matches.png)

## 能做什么

- **对局**：以地图图为背景的列表，只显示胜负、比分、地图和英雄。首次查询读完全部历史，之后只补新对局。点开是两层页面：整场对局，再点一名玩家是他的个人卡片（数据、段位、Fleta 指数）。
- **英雄**：每个英雄一张海报式详情页：赛季数据（每 10 分钟、每场平均）、近期对局、技能和威能。
- **对局强度**：每个职责取最近 N 场，比较己方与对方的段位，逐场画出平均和最低到最高的分布。
- **成长**：存活时长（保活能力）、Fleta 指数、KDA、治疗量、阻挡量的局间折线图，和各指标的走势检验。
- **赛季走势**、**档案**：往期赛季的胜率和段位；身份与近期表现。
- **导出**：统一格式的 JSON 数据集，不含凭据。

## 安装

1. 到 [发布页](https://github.com/KCN-judu/watch-overwatch/releases) 下载 `watch-overwatch-v<版本>-windows-x64.zip`，解压到任意目录（`watch-overwatch.exe`、`watchd.exe` 和 `data` 文件夹要放在一起）。
2. 双击 `watch-overwatch.exe`。它会自动启动同目录的 `watchd.exe`，关闭窗口时一起退出。
3. 需要 Microsoft Visual C++ 运行库（大多数电脑已安装）和一个大神账号的凭据，见 [获取账号凭据](credentials.md)。

从源码构建见 [快速开始](getting-started.md) 末尾和仓库的 README。

## 数据与隐私

- 账号凭据只保存在本机 `%LOCALAPPDATA%\Watch Overwatch\secrets.json`，不会出现在界面、日志、导出或仓库里。
- 请求只发往网易大神的接口；图片取自大神和暴雪的图片地址。
- 本机数据库里有对局里其他玩家的昵称和编号（对局详情里本来就有），没有任何令牌；设置页可以查看大小和清除。
- 职责、技能、威能等图标和资料来自游戏本体和暴雪、大神的公开资源，仅供个人使用，不属于本项目的开源内容。
