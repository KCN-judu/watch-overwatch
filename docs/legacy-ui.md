# 旧网页界面的退役

`ui/` 是 Flutter 界面之前的网页界面，由 `watchd` 在根路径 `/` 提供（单独运行时是 `http://127.0.0.1:18180/`）。1.4.0 里它和它的路由都还在，不再更新。下表逐项决定每个功能是迁移、已有替代，还是不做。

## 功能对等清单

| 旧网页界面 | Flutter 界面 | 决定 |
|---|---|---|
| 玩家库、查找玩家 | 左侧玩家库、搜索框 | 已迁移 |
| 档案（生涯、各职责段位、近期表现） | 档案页 | 已迁移 |
| 汇总（多页战绩汇总） | 概览页 | 已迁移，另加了近 20 场对比、近期动态、时段胜率 |
| 对局列表、对局详情 | 对局页 | 已迁移 |
| 历史赛季 | 赛季走势页（含段位轨迹） | 已迁移 |
| 诊断（请求记录） | 设置 → 请求记录 | 已迁移 |
| 设置（账号、缓存） | 设置页 | 已迁移 |
| 省榜（本人的省内排名） | 档案页“省榜排名” | 已迁移 |
| 英雄榜（本人的英雄排名） | 英雄详情标题栏“英雄榜：某省第 N 名” | 已迁移（issue #18） |
| 英雄榜、省榜的公共查询（任选省份、英雄看榜单） | — | 不做：这是浏览排行榜，不是分析一名玩家；接口 `POST /api/community`（`province`、`hero_board`）保留 |
| 英雄选取率（官方英雄统计，按段位） | — | 暂缓：官方接口 2026-10-22 返回“系统维护中”，字段无法核对；恢复后在英雄详情加全服同段位选取率和胜率，接口 `pick_rate` 保留 |
| 商店 | — | 不做：与战绩分析无关，官网和游戏内更全 |
| 补丁说明 | — | 不做：链接到官网即可；版本对数据的影响以后在段位轨迹的赛季分界上标注 |
| 赛事 | — | 不做：与战绩分析无关 |
| 暴雪玩家搜索、暴雪生涯页 | — | 不做：国服数据来自大神，暴雪国际服的生涯不是同一来源 |
| 英雄百科、地图猜题 | 英雄详情的技能与威能 | 百科部分由英雄详情替代；猜题不做（回顾里的“先猜再揭晓”是同类互动） |

## 退役计划

| 步骤 | 内容 | 状态 |
|---|---|---|
| 1 | Flutter 界面是唯一推荐的界面；旧网页界面仍随 `watchd` 提供，README 和本页写明不再更新 | 1.3.0 起已做 |
| 2 | 旧网页界面顶部提示“已停止更新，请使用 Watch Overwatch 桌面程序”；`/api/community` 里不做的查询（`shop`、`patch`、`esports`、`blizzard_search`、`blizzard_profile`）标为弃用 | 未做（1.4.0 仍无提示，这些查询未标弃用） |
| 3 | 删除 `ui/`、`watchd` 里提供它的路由（`/`、`/app.js` 等）和弃用的查询；保留 `province`、`hero_board`、`pick_rate`；在 CHANGELOG 的“变更”里写明 | 未做，在第 2 步之后的次版本 |

脚本和第三方调用只依赖 [本机接口](http-api.md) 里列出的 `/api/...` 接口，不受影响。
