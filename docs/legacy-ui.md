# 旧网页界面的退役

`ui/`（`watchd` 在 `http://127.0.0.1:18180/` 提供的网页界面）是 Flutter 界面之前的版本。下表逐项对比，决定每个功能是迁移、已有替代，还是不做。

## 功能对等清单

| 旧网页界面 | Flutter 界面 | 决定 |
|---|---|---|
| 玩家库、查找玩家 | 左侧玩家库、搜索框 | 已迁移 |
| 档案（生涯、各职责段位、近期表现） | 档案页 | 已迁移 |
| 汇总（多页战绩汇总） | 概览页 | 已迁移，并加了近期对比、值得注意、热力图 |
| 对局列表、对局详情 | 对局页 | 已迁移 |
| 历史赛季 | 赛季走势页（含段位轨迹） | 已迁移 |
| 诊断（请求记录） | 设置 → 请求记录 | 已迁移 |
| 设置（账号、缓存） | 设置页 | 已迁移 |
| 省榜（该玩家的省内排名） | 档案页“省榜排名” | 已迁移 |
| 英雄榜（该玩家的英雄排名） | 英雄详情标题栏“英雄榜：某省第 N 名” | 已迁移（issue #18） |
| 英雄榜、省榜的公共查询（任选省份、英雄看榜单） | — | 不做：这是排行榜浏览，不是对一名玩家的分析；接口 `POST /api/community`（`province`、`hero_board`）保留 |
| 英雄选取率（官方英雄统计，按段位） | — | 暂缓：官方接口 2026-10-22 返回“系统维护中”，字段无法核对；恢复后在英雄详情加“全服同段位选取率 / 胜率”，接口 `pick_rate` 保留 |
| 商店 | — | 不做：与战绩分析无关，官网和游戏内更全 |
| 补丁说明 | — | 不做：链接到官网即可；版本对数据的影响以后在段位轨迹的赛季分界上标注 |
| 赛事 | — | 不做：与战绩分析无关 |
| 暴雪玩家搜索、暴雪生涯页 | — | 不做：国服数据来自大神，暴雪国际服的生涯与本工具的数据不是同一来源 |
| 英雄百科、地图猜题 | 英雄详情的技能与威能 | 百科部分已由英雄详情替代；猜题不做（回顾里的“先猜再揭晓”是同类互动） |

## 退役计划

1. **现在（1.3.0）**：Flutter 界面是唯一推荐的界面。旧网页界面仍随 `watchd` 提供，README 和本页写明它不再更新。
2. **下一个次版本**：旧网页界面顶部显示“已停止更新，请使用 Watch Overwatch 桌面程序”的提示；`/api/community` 中不做的查询（商店、补丁、赛事、暴雪搜索与生涯）标为弃用。
3. **再下一个次版本**：删除 `ui/` 和 `watchd` 里提供它的路由（`/`、`/app.js` 等）以及弃用的公共查询；保留 `province`、`hero_board`、`pick_rate`。在 CHANGELOG 的“变更”里写明。

脚本和第三方调用只依赖 `docs/http-api.md` 里列出的 `/api/...` 接口，不受影响。
